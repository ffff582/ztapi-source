# 人民币参考汇率与服务器整改实施计划

> 执行方式：按既有工作区逐项执行，先失败测试、再实现、最后完整验收；不覆盖其他未提交修改。

**目标：** 人民币价格自动参考最新汇率，修正已证实的运维风险，保留客户资金、业务连续性和回滚证据。

**架构：** 展示汇率独立于计费和采购汇率，只读公开行情、使用有日期的缓存。发版镜像使用固定干净运行时基础，清理程序先计算受保护资源集合，再执行限定目录内的清理。资金争议仅导出证据与处理建议。

**技术栈：** Go、React/TypeScript、Python、Docker、systemd、现有健康 Telegram 通道。

**规格：** `D:/claude/移交Codex_服务器巡检整改_20261108.md`；用户批准上线自动更新的人民币参考展示。

## 全局边界

- 不修改客户密钥、余额、历史账单，不自动退款，不轮换数据库密码。
- 不撤销 fail2ban、保留 root 登录设置，不操作 kuaiyi 项目。
- Fable 仅按本次已批准范围移除渠道 2；其他渠道和全部售价保持不变，Flash 先查排除原因。
- 清理保留运行中容器引用、当前和前两版镜像、最近五个版本、恢复证据及所有明确保护的凭据。
- 应用代码须同一提交金融 CI 通过、公开 production 标签、候选验收及可回滚切换。

## 验收风险

- 汇率服务失败、周末和过期数据不能伪称实时价，更不能改变实际结算。
- Fable 发布变更应同步成本准入证明，不能导致推广活动静默失效。
- 清理不得跟随符号链接，不得依据未经核对的名称删除数据库、日志证据或回滚依赖。
- 旁路实例必须检查 nginx、任务入口和数据库权限后才能停止，不能只按创建日期判断。
- 预扣款清单区分测试和客户，未知实扣不得按零费用自动释放。

## 执行清单

- [ ] 只读快照：容器、流量、镜像层、磁盘、定时器、资金表结构、采购及发布策略。
- [ ] 展示汇率：服务及界面测试覆盖来源、日期、缓存、失败回退、独立计费边界，桌面与移动端验收。
- [ ] 固定基础镜像：连续构建两次验证层数和体积不随上一版增长。
- [ ] 运维保留策略：危险路径及依赖保护测试；自动发版收尾；journald 500M、ZTAPI 日志 50m×3、磁盘 80% 告警。
- [ ] 模型核查：Fable 快照只允许渠道 4且价格不变；Flash 给出是否故意排除的证据。
- [ ] 资金证据：逐笔导出 pending、关联请求和回执，给出待确认规则及历史 0.193258U事项；不改账。

- [ ] 发布门：精确提交 CI、生产标签、候选测试、连接排空、生产版本/就绪/页面检查。
