# 人民币充值入账实施计划

**范围：** 用户自填人民币金额，选择支付宝或微信；USDT 的订单、赠额、账本和路由保持原样。不新增套餐，不复用旧易支付入账回调。验收门槛全部通过前不开放。

1. 测试并实现独立人民币订单表。金额用分、额度用整数，持久化服务端报价；用用户和提交编号去重。锁订单和用户行，将余额、账本和订单状态放进同一事务。
2. 接入商户文档的易支付表单接口 `POST /api/epay/mapi.php`。后端只向固定 HTTPS 网关创建订单；GET 回调验签并核对预先绑定的商户、应用、订单标识、支付方式和金额。新入账还要求独立查单的已付结果完全匹配，提交后才确认。未确认的下单结果不自动重发，没有绑定支付单号的回调不得入账。
3. 钱包提供独立的人民币入口和状态显示。未配置验收条件时不开放新订单。实付按报价面值，不在首版验收中额外加 5%；不预设人民币赠额、返利或商户净额。
4. 原路全额退款先预留站内余额；单独核对商户退款凭证后才确认。商户文档未说明发起退款接口及退款金额、退款交易号字段，不能拿一个退款状态码直接冲账。未获得确凿失败证明不释放预留。部分退款和强制扣成负数不在首版。
5. 复用已付款的 1 元隔离原单验收；不再下单。已用原始签名通知回放两次，验证只入账一次。正式入口以真实收款、入账回调和同一提交财务 CI 通过为前提；用户端无自助退款，退款申请由客服处理，不将原路退款实测作为首发条件。当前不换密钥、不加 DNS。实扣、手续费、净结算币种缺失时，不将充值总额当成已结算收入或毛利。

## 小额真实验收前的检查

- 采用商户文档的易支付创建和 GET 签名通知；不启用旧易支付接口。回调可不带可选的 `param`，非空值必须匹配原单。查单只发送派生签名，不发送密钥原文；查单签名规则和实际返回仍待商户验收，返回成功但身份不匹配不算证据。
- 收银台支持可信 HTTPS 跳转或 `qrcode` 扫码。二维码在用户浏览器本地生成，接受可信 HTTPS 地址及微信官方 Native 支付格式；不把二维码内容作为跳转地址。文档未给出小程序 `urlscheme` 的可信格式，暂不启用该跳转。
- 隔离实测：支付宝下单 API 在 `ttzf8.com`，实际回执返回 HTTPS 收银台 `hm367.com`。仅配置该精确收银台主机 `ZTAPI_CNY_TOPUP_CHECKOUT_HOST=hm367.com`。已付款订单按商户订单号、黑猫平台订单号查询，均确认金额和支付状态，但返回 `pid: null`。仅在付款通知已验签并确认应用归属、订单已预先绑定黑猫平台单号、独立查单的两个订单号、支付方式、金额和支付状态均匹配时兼容此响应。缺字段、空字符串、错误应用 ID 仍然拒绝，不能只凭查单或只凭回调入账。
- ZTAPI 财务后台的「人民币订单」只读页按商户或黑猫平台订单号精确检索，区分应付与已核验实付，不显示支付链接或密钥。无黑猫平台单号时标为待核对，不把站内待支付订单算成实收。
- 通过结算单确认收单方、净结算币种、费率计算基数、实扣、实际入账及退款手续费。人民币实付在独立订单留存，尚未将其并入财务毛利；待收齐实际凭证后补入财务归集并完成核对。5% 的 USDT 赠额规则保持原样，不自动扩展到人民币，也不添加 5% 人民币附加费。
- 试验仅使用验收账号。`ZTAPI_CNY_TOPUP_ENABLED` 默认关闭；先在独立测试实例配置 `ZTAPI_CNY_TOPUP_TEST_USER_ID`、`ZTAPI_CNY_TOPUP_MIN_CNY=1`、`ZTAPI_CNY_TOPUP_MAX_CNY=1` 和经确认的 `ZTAPI_CNY_TOPUP_CNY_PER_U`，不要设置 `ZTAPI_CNY_TOPUP_PUBLIC=true`。通过现有域名的精确回调路径转发到隔离服务，确认入口代理及应用访问日志都不记录查询串。商户凭据由服务端配置，禁止提交；公开开放前建议轮换已暴露的密钥。关停新单后保留在途单核销能力。
- 对照同一商户订单验证用户实付、回调金额、到账 U、重复通知无二次入账。收银台跳回页面不触发入账。未确认下单不得反复向商户发起新的同一订单；先在商户后台查清。
- 原路退款前由管理员二次验证并调用 `POST /api/admin/payments/cny/:order_no/refund/hold`，读回待退款状态和额度预留，再在商户后台实际操作。随后从支付方凭证核对原交易号、退款交易号、全额退款金额和原路最终状态，调用同路径 `/confirm`。未经核验的通知不扣减或恢复余额。当前无自动退款和失败后自动解除预留，需按商户最终结果复核。
- 生产从权限为 0600 的 `/etc/ztapi/cny-topup.env` 读取配置，默认没有该文件且不开放。首发仅配置已验收的 `ZTAPI_CNY_TOPUP_METHODS=alipay`，`ZTAPI_CNY_TOPUP_CNY_PER_U=7`，按实付面值计算，不额外加收手续费；正式单笔上下限待确认。回调只在公开 HTTPS 站点接收，不记录签名查询串。
- 回调验收失败、账务不一致或财务 CI 不通过，继续关闭公开入口；USDT 不需要随之下线。
