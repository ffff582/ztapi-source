# 人民币充值返利实施计划

## 准入证据

两笔隔离验收单分别为支付宝、微信支付，各实付 ¥1.00，充值账本各入账一次，黑猫商户账本各净入账 ¥0.95。5% 是本次两笔的实扣费率，不作为未来永久费率保证。以当前 FX 参考中较高值和已通过的 89 项成本凭证计算，按实付再预留 5% 返佣，最低毛利约 12.32%。不改充值汇率、入账或原有 USDT 活动。

## 实施与验收

1. 在独立、默认关闭的人民币返佣政策里固定启用时间、商户、支付方式、汇率和额度换算，以及可验证的手续费上界。沿用目录和成本有效期检查，人民币任一维度低于 10% 时不新增返佣，USDT 不受影响。测试 10% 边界、失效配置和两个支付方式。
2. 人民币订单结算后，由独立对账从支付订单与不可变充值账本生成佣金，按实际入账额度本金的 5% 向下取整。要求下单、支付、绑定均在适用窗口内，首次启用之前下的单不计佣。人民币使用独立订单来源键，既不重用 USDT 订单编号，也不重复写充值账本。测试两个方式、旧单、重复、坏凭证和 USDT 混合数据。
3. 提现预留和领取付款任务时核验人民币来源状态，退款处理中不得新提现；退款确认后按现有佣金冲回规则记负向分录。已付款的差额继续计入人工损失，不扣用户余额。测试全额冲回、重复退款、已预留和已付款的情况。
4. 显示支付方式及人民币返佣启用状态。先上默认关闭的兼容代码，验证迁移、混合订单、跨库和金融 CI；发布时重验相同目录和成本凭证，最后启用并只读复核。禁止为验收新建真实订单或打款。

滚动发布时，受保护的成本凭证只接受两个经过同目录复算的准确指纹，过渡指纹必须过期，避免旧、新 API 切换期间关闭 USDT 邀请。首次记入人民币佣金后，回滚只关闭新计佣政策，不降级佣金表或停止退款冲回任务。
